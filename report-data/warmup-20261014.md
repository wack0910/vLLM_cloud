# 워밍업 실행 확인 — 2026-10-14

최종 Word 보고서의 사전 실행 확인 자료. 본 측정 및 파라미터 튜닝 결과와 별도 분류한다.
사용자가 제공한 콘솔 스크린샷을 전사했다. 원본 JSON 및 실행 환경 정보는 아직 받지 않았다.
모델 이름, 서버 설정, 요청 옵션은 이 이미지 자체에서는 확인할 수 없으므로 이전 계획과 동일하다고 확정하지 않는다.

## 파생값과 해석

- 관측 성공률: 20 / 20 = 100%.
- 요청당 평균 출력: 2560 / 20 = 128 tokens.
- 요청당 평균 입력: 20729 / 20 = 1036.45 tokens. 입력 목표가 1024였다면 차이는 12.45 tokens/request이나, 원본 요청·토크나이저 확인 없이 원인을 확정하지 않는다.
- 평균 첫 출력 대기 약 1.174초, 평균 요청 완료 약 7.045초.
- 72.55 output tok/s는 이 워밍업 전체의 집계 처리량이며 요청 하나의 생성 속도와 다르다.
- 96.00 peak output tok/s와 659.97 total tok/s는 주 처리량 비교값을 대체하지 않는다. 보고서의 처리량 비교에는 평균 output tok/s를 사용한다.
- 워밍업 20개 요청 완료로 해당 실행에서의 정상 응답을 확인했다. 장시간 안정성, 최대 처리량, 최적 설정의 근거로 사용하지 않는다.
- p99 ITL 209.25ms는 일부 스트리밍 출력 간격이 길었음을 보여준다. 단일 워밍업만으로 병목 원인을 판단하지 않는다.
- KV Cache 사용률과 캐시 용량은 이미지에 없으므로 미측정/미제공으로 남긴다.
- 콘솔의 Maximum request concurrency=4와 Peak concurrent requests=8.00은 구분하여 원문 그대로 보존한다. 원본 JSON, vLLM 버전 및 해당 지표 산식을 확인하기 전에는 서버가 실제 8개 요청을 동시에 실행했다고 해석하지 않는다.

## Word 보고서에 사용할 문장 초안

본 측정 전 워밍업에서는 동시 요청 한도 4에서 20개 요청이 모두 성공하였다. 평균 TTFT는 1,174.02ms, 평균 TPOT는 46.23ms/token, 출력 처리량은 72.55tokens/s로 관측되었다. 이 결과는 실행 경로 확인 자료로 사용하고, 설정 비교 및 안정성 평가는 별도의 반복 본 측정 결과를 기준으로 수행한다.
